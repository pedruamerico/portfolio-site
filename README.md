# Pedro Américo — Portfolio

Personal portfolio for **Pedro Américo**, software engineer working from
product to production: application development, CI/CD and cluster operations.

**Live:** [pedroamerico.com](https://www.pedroamerico.com/)

## What it covers

- Products available for hire (landing pages, SaaS, desktop apps, APIs, infra)
- Build / Deliver / Operate: how the work is organized
- Selected projects: Spotar and Log Pose
- Stack grouped by role
- Career path and contact channels

Content is available in Portuguese and English, with a dark and a light theme.

## Stack

- React 19 + TypeScript
- Vite 7
- Plain CSS (design tokens as custom properties, one stylesheet per component)
- Motion with CSS keyframes and `IntersectionObserver` only
- Vercel Analytics

## Run locally

Prerequisite: Node.js LTS.

```bash
npm install
node scripts/fetch-icons.mjs   # once: downloads the stack logos into public/icons/
npm run dev
```

Production checks:

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

## Structure

```text
index.html                 metadata, Open Graph, fonts, theme/lang bootstrap
public/
├── photo.webp  og.png     portrait and social image
├── projects/              project screenshots
├── icons/                 stack logos (generated by scripts/fetch-icons.mjs)
└── robots.txt  sitemap.xml
scripts/fetch-icons.mjs    downloads the logos from Simple Icons / Iconify
src/
├── data/content.ts        all PT/EN copy: hero, products, layers, projects, stack, path, contact
├── hooks/                 useReveal (scroll reveal + layer cycle), useLanguage, useTheme
├── components/            one section per component, with its own .css next to it
├── index.css              tokens, dark/light, grid, buttons, keyframes, reveal rules
├── App.tsx                section order
└── main.tsx               application entry point
```

Section order: Header · Hero · Products · Build/Deliver/Operate · Projects ·
Stack · Path · Contact · Footer.

## Deployment

The production site is deployed on Vercel. Pushes to the production branch
trigger a new deployment.
